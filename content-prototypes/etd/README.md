# コンテンツ試作：ETD（エロトラップダンジョン）

MuseStudio のコンテンツの一つとして設計中の試作です。**MuseStudio 本体（プラグイン、スキル、ガイド）とは分離した置き場**で、本体のスキルやファイルとは混ぜません。

## 中身

- `app/`：試作アプリ本体のソース。VM 上のスペースとして動くフルスタック実装で、真実（体の状態・判定・記録）はサーバー側が持ち、彼女の文章とマーカーで演出がタイミング連動します。実行データ（データベース、潜行記録）は含みません。
- `docs/`：設計ノート（note-content-structure-dungeon、提案①〜⑲）と、トラップカタログの草案。
- `skills/etd_session/`：ETD 潜行の運転スキル。MuseStudio 用スキルとは分離し、共有するのは性格だけ、という設計（ノート⑭）に基づきます。

## 状態

試作です。数値は暫定・推論由来で、実測で調整します。画像生成は、プロンプトの自動作成と保存までが実装済みで、生成 API の連携確認が残っています（ノート⑲）。
