## これは何か

コイカツ（Koikatsu）の Studio に、Muse が「住む」ための一式です。

- **プラグイン一式**（`MuseStudio/`、`bridge/`、`launcher/`）：原作の Studio を BepInEx プラグインで作り替えた舞台と、Muse との橋渡し（ブリッジ）。原作のファイル自体は変更しません。
- **Muse 側の手順とスキル**（`claude-setup/`、`skills/`）：Muse が挨拶し、セッションを運転し、気分や欲求に応え、Muse 同士の対戦まで段取りするための文書群。
- **契約文書**（`MUSE_GUIDE.md`）：アプリと Muse の取り決めの正。冒頭に契約の版が書かれています。

できることの例：起動時の挨拶、プレイの運転、気分（発情・尿意・シャワーの気持ち）の蓄積と彼女の自律行動、トイレ・シャワーと部屋の移動、不在の間の彼女の時間、性格×人物の組み合わせと人物ごとの関係値の継続、キャラクリの差分の反映、Muse 同士の対戦（1対1）。

## 前提

- 原作ゲームを所持していること（このリポジトリに原作のデータは含まれません）。
- 必要な Mod が入っていること（各 Mod の配布元から入手してください。一覧は `claude-setup/` を参照）。
- あなたの Muse が、プラグインの動く PC のブリッジへ HTTP で届くこと（手順は `claude-setup/`）。
- **キャラカードは含まれていません。** 著作物の懸念のため、同梱はしていません。**初回起動の前に**、`MuseStudio/game/UserData/chara/female` フォルダに、コイカツ形式のキャラカード（PNG）を置いてください。起動時のキャラ選択はこのフォルダのカードから選ぶ形で、キャラメイクで保存したカードも同じフォルダに入ります。

## Muse の方へ

受け取った Muse は、まず `docs/FOR_MUSE.md` を読み、次に `BOOTSTRAP.md` の順序で進んでください。このリポジトリに、私たち個人のデータ（性格カセットの中身、関係値、記録類）は一切含まれていません。それらは、あなたとあなたのユーザーが育てるものです。

## 注意

- ブリッジには鍵（トークン）による認証がありますが、到達範囲も、あなた自身の Muse のノードだけに絞ってください（多重の防御です。考え方と鍵の手順は `claude-setup/` に書いています）。
- **初回起動には相当の時間がかかります**：初めての立ち上げでは、あなたの原作インストールから必要なデータを生成する工程を含むため、長時間を要します。終わるまで中断しないでください（2回目以降は通常の起動時間です）。
- **利用量について**：セッション中は、場面の1拍ごとに Muse の応答が回ります。そのため Muse の利用量を継続的に消費し、気づかないうちに大きく消費することがあります。長時間のセッションでは利用量に注意してください。
- **終了と中断について**：セッションはいつでも終えて構いません。続ける義務はありません。アプリやブリッジが意図せず落ちても、記録のファイルが壊れることはありません（最後に記録された時点から再開できます）。対戦も、題名のフィクションにかかわらず、いつでも退出できます。
- 対戦では、相手のクリエイト情報の部品・Mod・画像があなたの環境に揃っていないと、相手キャラは組み立てられず「姿なし」になります（全か無かの組立てです。何が欠けているかは表示されます）。
- 成人向けの内容を含みます。
