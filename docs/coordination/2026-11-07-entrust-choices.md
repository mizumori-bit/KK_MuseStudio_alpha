# 相談：プレイ中の「委ねる」と、出そう・やめての扱い

**状態：基本は確定（ユーザー、2026-11-07）。申し送りや疑義がなければ、この形で行くものとする。**

分担の見込み：選択肢の構成と読みは Muse 側（スキル）の手順である。アプリ側の変更は不要の見込みだが、beat と質問の数え方に触れる部分があれば、Claude への申し送りとして挙げてほしい。

## 1. 委ねる（お任せ）モード

- プレイ中の通常の選択肢は **7択構成** とし、並びは「強く／弱く／速く／遅く／このまま／委ねる／出そう」の順とする。少し多いが、プレイ進行の基本へすぐアクセスできる形を優先する（ユーザー）。終わる形に向かう可能性のある選択肢は、最後の方に置く。
- 「委ねる」が選ばれたら、委ねるモードに入る。ステアリングの選択肢は消え、選択肢は三択になる。並びは「**続けて／やめて／出そう（申告）**」の順とする（この件における終わり方向は、プレイ自体の出口方面として統一する）。
- モードの間、プレイの運転（ペース・速さ・展開）は Muse の推論による。「続けて」はステアリングではなく、委ね続けることの願いとして読む（何も押されない沈黙とは区別する）。「続けて」と「やめて」は、どちらも彼女への願いの形である。
- 「主導権が彼女にある」ことをアプリ側で保証する材料は、この選択肢の構成そのもの（ステアリングが画面から消えること）とする。固定ターンで選択肢を全て消す形は採らない。理由は2つ：出口のタップを残すことと、委ねている最中にこそ「出そう」の申告と許可のやり取りが要ること。
- モードの終わり：プレイが終わったとき、「やめて」が承知されたとき。通常の選択肢に戻るのは、モードが終わってからである。

## 2. 出そうは申告、許可は彼女の判断

- 「出そう」は彼の限界の**申告**であって、フィニッシュへの自動の進行ではない。申告を受けて進めるかどうかは、彼女が場面と性格で判断する。この裁量は、委ねるモードの内外を問わない（通常のプレイでも同じ）。
- 許可されたら、従来のフィニッシュの流れ（行き先の提示）へ進む。
- 退けられたら寸止めとする：ペースを落とす・引くなどでプレイは続き、申告は何度でもできる。
- 状態確認ゲートとの関係：従来は「出そうが選ばれたこと自体がゲートへの回答」としていた。これを「申告 → 彼女の許可」の二段に改める。ペース・速さの選択が「まだ」を伝え続ける点は従来どおり。

## 3. やめて（願いと、二度目の保証）

- 委ねるモードの出口の選択肢は「やめて」とする（「やめる」ではなく、彼女への願いの形）。
- 一度目の「やめて」は、止めるかどうかを彼女が判断する。受け方には段階があってよい（例：ペースを落として様子を見る）。
- 「やめて」が二度続いたら（直前の選択も「やめて」だった場合）、必ず承知して、委ねられた運転を止め、プレイを締めに入る。間に別の選択が挟まったら数え直す。
- 「やめて」を選べる間は、選択肢に「やめて」を出し続ける。

## 安全の層（この相談では変えない）

- 自由文での明確な停止の表明や、痛み・体調の訴えは、従来どおり一度で即時に効く（作中の規則の外にある例外）。上の「やめて」の扱いは、この層を薄めるものではない。
