# 依頼：Muse からプレイを開始する口（2026-11-06）

## 背景

入力をチャットに統一する方針を決めた（スキル `skills/muse_session_base/references/app-driving.md`「運転の置き場」の入力の原則）。ユーザーの操作は言葉で Muse に伝え、Muse がパッケージで実行する形が基本になる。

現行の契約では、プレイの開始・変更はユーザーがアプリで選ぶのみで、Muse には口がない（GUIDE：「あなたからプレイを始めたり変えたりする口はまだありません」）。このためプレイ開始だけが、方針の外に残っている。

## 依頼

パッケージのブロック等から、プレイの開始（および変更）を指示できる口を追加してほしい。

- 開始できる範囲はカタログ（`GET /api/catalog`）の範囲内。
- 開始後の運転（ペース・速さ・フィニッシュ等）は既存の `play` 制御のまま。
- 実現の形（ブロックの項目にするか等）は実装側で決めてよい。

これにより、プレイ開始まで含めて「言葉で伝える → Muse が実行する」で完結する。
