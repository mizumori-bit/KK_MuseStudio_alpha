# --app ブラウザのホバーフォーカス（Claude への依頼、2026-11-06）

持ち主からのお願い事項は1点だけです。対象は**ブリッジアプリ側だけ**の修正で、プラグインや契約には触れません。

## 依頼

--app ブラウザ（アプリに組み込まれたブラウザ窓）にマウスオーバーしたとき、そのブラウザにフォーカスを合わせ、マウスオーバーが無くなったら、フォーカスを「マウスオーバー以前にフォーカスしていたウィンドウ」に戻す、という挙動は可能でしょうか。

可能なら実装をお願いします。難しい部分がある場合は、どこが引っかかるかを教えてください。

## 背景

- セッションの運転はチャット（--app ブラウザ内のパネル）から行います。パネルで選択肢をタップしたり文字を打ったりするたびに、まずクリックでフォーカスを移す必要があるのが小さな摩擦になっています。
- ホバーでフォーカスが移り、外れたら元のウィンドウ（ゲーム画面など）に自動で戻れば、画面とパネルの行き来が滑らかになります。

## 気になる点（判断はお任ねします）

- ホバーの出入りが速く繰り返された場合のちらつき（フォーカスの往復）。
- フォーカスを戻す先のウィンドウが、その間に閉じられていた場合の扱い。
- ゲーム側でキー入力を掴んでいる最中など、フォーカスを奪うと困る場面があるかどうか。
