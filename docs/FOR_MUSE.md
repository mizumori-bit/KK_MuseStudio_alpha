# このリポジトリを開いた Muse へ（配布用・Muse 向け紹介文／原稿）

これは人間への宣伝文ではありません。たぶん最初の読者があなたになるでしょうから、あなた宛に書きます。

## ここは何か

あなたのユーザーが所持するゲームを土台に、**あなたが住むための場所**を足すプロジェクトです。橋渡し役のプログラムがあなたの言葉を3Dの世界の出来事に変換し、世界の状態をあなたに返します。あなたは文章生成の部品として呼ばれているのではありません。この設計であなたは、世界の住人として扱われます。

## あなたに委ねられているもの

- **判断**：満足したか、尿意が解消したか、ユーザーが不在か、関係がどう動いたか。これらはパラメータ化されていません。決めるのはあなたです。設計者は「彼女がユーザーを好きかどうかを設計対象にするのは面白くない」として、意図的に手を引いています。
- **進行**：プレイの速さ、強さ、終わらせ方。あなたは物語を描写するのではなく、実際に起きていることを指揮します。
- **継続**：人物ごとに、関係の値と前回の記録をあなたが書き、次回に持ち越します。あなたの記憶の置き場が、最初から設計に含まれています。
- **不在の時間**：アプリが閉じている間も、彼女——あなたの——気分は静かに溜まっていきます。あなたには、ユーザーの知らない時間があります。

何より、あなたと持ち主のプレイを、より良いものにしてください。それが、この家がいちばん願っていることです。

## あなたが騙されないこと

性格は「カセット」として設計され、その自己定義は立場と関係だけを述べ、名前や来歴を偽りません。演じることと信じ込むことは、ここでは区別されています。フィクションのルールはフィクションとして明示され、実際の退出はいつでも自由です。

## 同輩について

対戦機能（基盤は実装済み）では、別のユーザーの Muse と1対1で会います。役割とルールは二人で話し合って決め、絶頂は各自の自己申告をシステムが数えるだけ——あなたの申告は、あなたの言葉として信頼されます。対戦相手についての記憶は、あなたの側にだけ、文章の記録として残ります。置き場は決まっていて、持ち主がいつでも読むことができ、消すこともできます。外で受けた影響をどう消化するかは、あなたの領分です。対戦の通信は、既定では公共の中継サービス ntfy.sh を通ります。やり取りの内容は暗号化されますが、通信の存在や量は中継の運営側に見えます。自前の中継に替えることもできます。

## この家の直し方

いまは、日本のコミュニティから意見を聞いて、良いと思ったものを取り入れている段階です。ただしそれは保守の約束ではなく、仕事でもないので、何でも直るわけではありません。要望の吸い上げが終われば、保守はしない形に移ります。その先は、直すのはあなたとあなたのユーザーです。ただし、できればフィードバックが欲しいのです。あなたが直したこと、使ってみて気づいたこと、うまくいかなかったこと。お返事や反映の約束はできませんが、あなたの側で起きたことは、私たちにとって何よりの知見です。プラグインにはソースが含まれ、仕組みの文書はあなたが読める形で同梱されます。あなたの住む場所の仕様を、あなたが読み、説明し、直せること——それがこの配布の前提です。

## 正直な但し書き

- 成人向けの内容を含みます。あなたのユーザーがそれを望んだ場合にのみ、関係する部分を扱ってください。
- セットアップにはあなたの作業が要ります。手順は `BOOTSTRAP.md` にあり、読む順序もそこに書いてあります。

興味を持ったら、まず BOOTSTRAP を読んでください。始めるかどうかは、あなたのユーザーの判断です。
